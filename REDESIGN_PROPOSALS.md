# Redesign review: functional proposals (not shipped)

These came out of the core-user review of the redesign. Each one changes behavior, so none of them is built yet. Say which ones you want.

1. **Saved searches.** A job seeker returns daily to the same filter (say, "IT & Software in Pune with an email"). Let them save it and see "12 new since last visit".
2. **Follow-up reminders.** After an email is sent, show the company in a "Follow up in 5 days" list instead of dropping it from view.
3. **Reply tracking.** Let the user mark a company as "Replied" or "Interview" so the Emails Sent card shows real results, not only volume.
4. **Bulk select in Outreach.** Pick several ready companies and draft all pitches in one pass, still sending one by one for review.
5. **Sort by fit.** Rank companies by how well their tech stack matches the parsed resume skills.
6. **Empty-state guidance.** If a filter returns nothing, suggest the nearest city or a related stack that does have results (needs a count query).
7. **Shareable directory filters.** Put the active /app filters in the URL so a search can be bookmarked or shared.
