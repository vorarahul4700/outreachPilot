Cryptographic Security & Storage

Infrastructure Security
lock Key Takeaway: OAuth tokens are symmetrically encrypted at rest with Fernet (AES-128-CBC) before database writes.

All OAuth refresh tokens and credentials are encrypted at rest using industry-standard Fernet (AES-128-CBC) symmetric cryptography before persisting to the database. Uploaded resume files are parsed in memory and wiped from disk immediately upon skill extraction.
